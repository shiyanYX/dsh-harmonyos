@Entry @Component struct Index { @State message: string = 'Hello World' build() { Column() { Text(this.message) .fontSize(50) .fontWeight(FontWeight.Bold) } } }
已完成 · 0.3s

核心相似点：

  • 都是声明式 UI
  • 都支持状态驱动：@State vs useState
  • 都有组件化思想

关键差异：

  • ArkUI 用链式装饰器，React 用 props
  • ArkUI 有内置生命周期装饰器，React 用 Hooks
