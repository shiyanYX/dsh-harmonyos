# DSH HarmonyOS Client — 设计令牌系统 (Design Tokens)

> 所有视觉规范的基础层，所有组件样式从此派生。

---

### 1.2 功能色 (Semantic Tokens)

| 令牌名 | 值 | 用途 |
|--------|-----|------|
| `--accent-blue` | `#4a9eff` | 主强调色（选中态、链接、发送按钮） |

### 1.3 交互态色

| 状态 | 背景 | 说明 |
|------|------|------|
| Default | 透明 | 默认状态 |

## 2. 字体排印

### 2.1 字体族

```
font-family: -apple-system, 'HarmonyOS Sans SC', 'PingFang SC', system-ui, sans-serif;
```

- **HarmonyOS Sans SC**：鸿蒙系统字体，优先使用
- **PingFang SC**：iOS/macOS 回退
- **system-ui**：通用系统字体回退

### 2.2 字号系统

| 用途 | 字号 | 行高 | 字重 |
|------|------|------|------|
| 大标题 | 20px | 28px | 700 |
| 页面标题 | 17px | 24px | 600 |
| 卡片标题 | 15px | 22px | 500 |
| 正文 | 15px | 22px | 400 |
| 辅助文字 | 14px | 20px | 400 |
| 小字/标签 | 13px | 18px | 500 |
| 时间戳 | 12px | 17px | 400 |
| 极小标签 | 10px | 14px | 500 |
| 代码 | 12-13px | 17px | 400 (monospace) |

### 2.3 中文排印规则

- 标题字间距：`letter-spacing: -0.3px`（紧凑感）
- 正文不用 `letter-spacing`
- 数字和英文用等宽字体：`font-family: monospace`
- 代码块行高：`line-height: 1.4`

## 6. 动画系统

### 6.1 缓动曲线

| 名称 | 值 | 用途 |
|------|-----|------|
| 弹性 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 按压反馈、弹出 |
| 平滑 | `cubic-bezier(0.4, 0, 0.2, 1)` | 一般过渡 |
| 渐入 | `cubic-bezier(0, 0, 0.2, 1)` | 淡入 |
| 渐出 | `cubic-bezier(0.4, 0, 1, 1)` | 淡出 |

### 6.2 时长

| 场景 | 时长 |
|------|------|
| 微交互（按压） | 150-180ms |
| 菜单弹出 | 300ms |
| 弹窗弹出 | 350ms |
| 页面切换 | 250-300ms |
| 持续动画（脉冲） | 2-3s 循环 |

### 6.3 关键动画

| 动画名 | 实现 | 用途 |
|--------|------|------|
| `tabLight` | radial-gradient 脉冲 3s | Tab 项选中点光源 |
| `fabGlow` | radial-gradient 脉冲 2.5s | FAB 按钮光晕 |
| `menuIn` | translateY(8px) scale(0.96) → 正常 | 菜单弹出 |
| `dialogIn` | translateY(20px) scale(0.95) → 正常 | 弹窗弹出 |
| `edgeGlow` | 渐变边框 opacity 脉冲 3s | 边缘流光 |
| `pointLight` | radial-gradient scale 脉冲 2s | 发送按钮点光源 |
