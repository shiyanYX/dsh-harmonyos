## 2. 消息流区域

### 2.1 消息类型

| 类型 | 说明 | 样式 |
|------|------|------|
| **系统消息** | 会话创建、模型切换等 | 居中胶囊，小字，半透明背景 |
| **用户消息** | 用户输入的文字 | 右对齐，蓝色气泡，圆角 20/20/4/20 |
| **Assistant 消息** | AI 回复（含文字+工具调用） | 左对齐，头像+内容，无气泡背景 |

### 2.2 Assistant 消息结构

```
Assistant Message
├── Avatar (30px 圆形，渐变背景)
└── Content (flex:1)
    ├── Text Paragraph (p)
    ├── Tool Call Card (tc) [可选，多个]
    ├── Text Paragraph (p)
    └── ...
```

### 2.3 滚动行为

- 容器：`flex:1; overflow-y:auto`
- 滚动条：3px 宽，半透明，`::-webkit-scrollbar`
- 新消息自动滚到底部
- 滚动时标题栏渐变模糊（`bindToScrollable`）

## 3. 工具调用卡片 (Tool Call Card)

### 3.1 结构

```
┌─────────────────────────────────────┐
│  📄 read_file                        │  ← 工具类型图标 + 名称
│  entry/src/main/ets/pages/Index.ets  │  ← 文件路径（单行截断）
│  ┌─────────────────────────────────┐│
│  │ @Entry                          ││  ← 代码块（可滚动）
│  │ @Component                      ││
│  │ struct Index {                  ││
│  │   @State message: string = ...  ││
│  │ }                               ││
│  └─────────────────────────────────┘│
│  ✅ 已完成 · 0.3s                    │  ← 状态指示
└─────────────────────────────────────┘
```

### 3.2 工具类型与颜色

| 工具类型 | 图标 | 背景色 | 说明 |
|---------|------|--------|------|
| `read_file` | 📄 | `rgba(74,158,255,0.15)` | 读取文件 |
| `write_file` | ✏️ | `rgba(52,211,153,0.15)` | 写入文件 |
| `bash` | 💻 | `rgba(167,139,250,0.15)` | 执行命令 |
| `search` | 🔍 | `rgba(74,158,255,0.15)` | 搜索 |

### 3.3 样式

- 容器：`background: var(--tool-card)`，`border-radius: 12px`
- 边框：`1px solid var(--border-subtle)`
- 代码块：`background: rgba(0,0,0,0.3)`，`border-radius: 8px`，等宽字体
- 状态指示：绿色圆点 + 文字

## 4. 权限审批卡片 (Approval Card)

### 4.1 触发条件

Agent 需要执行以下操作时弹出：
- 执行 shell 命令（`bash`）
- 写入/删除文件（超出当前权限预设）
- 其他需要用户确认的操作

### 4.2 结构

```
┌─────────────────────────────────────┐
│  ⚠️ Agent 请求权限                    │  ← 警告图标 + 标题
│  bash · hvigorw assembleHap         │  ← 操作描述
│                        [拒绝] [允许]  │  ← 操作按钮
└─────────────────────────────────────┘
```

### 4.3 样式

- 材质：**ULTRA_THICK**（`blur(80px) saturate(2.2)`）
- 背景：`rgba(40,35,20,0.88)`（暖色调，与冷色 UI 区分）
- 边框：`1px solid rgba(251,191,36,0.15)`（黄色警告色）
- 边缘流光：暖色渐变边框 + 脉冲动画
- 弹出动画：`@keyframes dialogIn`（translateY + scale + 弹性曲线）
- 按钮：「拒绝」透明边框，「允许」蓝色半透明背景

## 5. 输入区域 (Composer)

### 5.1 结构

```
┌─────────────────────────────────────┐
│  Card (REGULAR Material)             │
│  ┌─────────────────────────────┐    │
│  │ textarea                    │    │  ← 多行输入框
│  │ (placeholder: "输入消息...")  │    │
│  ├─────────────────────────────┤    │
│  │ 📎  🔒工作区 ▾  │ 🧠mimo ▾ 32% ▶ │  ← Toolbar
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘
```

### 5.2 输入框

- 最小高度：42px（单行）
- 最大高度：160px（多行自动扩展）
- 内边距：`12px 16px 4px`
- 背景：透明（Card 本身提供背景）
- 边框：无（Card 边框提供）
- 聚焦：Card 边框变为蓝色 `rgba(74,158,255,0.3)` + 光晕

### 5.3 工具行 (Toolbar)

**左侧工具**：

| 按钮 | 图标 | 功能 | 样式 |
|------|------|------|------|
| 附加文件 | 📎 | 附加文件/图片 | 普通按钮 |
| 权限预设 | 🔒 | 切换权限级别 | THIN 材质 + 下拉 |
| Plan | — | Plan 模式开关 | 普通按钮 |

**右侧工具**：

| 按钮 | 图标 | 功能 | 样式 |
|------|------|------|------|
| 模型选择 | 🧠 | 切换模型 | THIN 材质 + 下拉 |
| 上下文 | ⏱️ | Token 使用量 | 标签显示百分比 |
| 发送 | ▶ | 发送消息 | 渐变背景 + 点光源 |

### 5.4 发送按钮状态

| 状态 | 样式 | 交互 |
|------|------|------|
| 禁用（输入为空） | 灰色背景，无动画 | 不可点击 |
| 激活（有输入） | 蓝色渐变 + 光晕脉冲 | 可点击，scale(0.85) |

## 6. 权限预设下拉菜单

### 6.1 三级权限

| 级别 | 图标 | 背景色 | 说明 |
|------|------|--------|------|
| 仅可查看 | 👁 | `rgba(255,255,255,0.06)` | 只读，不可修改文件 |
| 工作区内修改 | ✏️ | `rgba(74,158,255,0.12)` | **默认**，仅修改工作区内文件 |
| 完全权限 | 🔓 | `rgba(239,68,68,0.12)` | 可执行任意操作 |

### 6.2 菜单样式

- 材质：**THICK**（`blur(60px) saturate(2.0)`）
- 弹出：非线性形变（`@keyframes menuIn`）
- 边缘流光：`::before` 渐变边框 + 脉冲
- 选中项：蓝色文字 + ✓ 图标
- 每项按压：`scale(0.97)`

## 10. 空状态

### 10.1 无消息时

- 显示会话创建提示胶囊
- 文字：「新会话已创建 · {model}」
- 样式：居中，小字，半透明背景

### 10.2 加载中

- Assistant 消息区域显示打字光标动画
- 光标：2px 宽，蓝色，`@keyframes bk` 闪烁

## 11. 交互状态机

```
[空闲] → 用户输入 → [有输入]
  │                    │
  │                    ├→ 点击发送 → [发送中] → [等待响应] → [空闲]
  │                    │
  │                    ├→ 点击权限切换 → [权限菜单打开]
  │                    │
  │                    └→ 点击模型切换 → [模型菜单打开]
  │
  ├→ 收到工具调用 → [工具执行中]
  │                    │
  │                    ├→ 需要审批 → [审批卡片显示]
  │                    │              ├→ 允许 → [工具执行中] → [完成]
  │                    │              └→ 拒绝 → [工具被拒绝] → [完成]
  │                    │
  │                    └→ 无需审批 → [工具执行中] → [完成]
  │
  └→ 收到最终回复 → [空闲]
```
