# DSH HarmonyOS Client — 导航流程与页面布局规格

---

## 1. 页面层级

```
Level 0 — 启动层
├── Splash Screen
├── Server Connection Page
└── Authentication Page

Level 1 — 主框架层（HdsNavigation + HdsTabs）
├── Tab 0: Workspace（服务器/工作区）
├── Tab 1: Favorites（收藏）
└── Tab 2: Settings（设置）

Level 2 — 对话层（全屏沉浸，无底部 Tab）
└── Chat Page（聊天界面）

Level 3 — 子页面层
├── Server Detail（服务器设置）
├── Permission Preset Menu
├── Model Selection Menu
└── Main Menu (⋯)
```

---

## 2. 导航流程

### 2.1 页面切换规则

| 操作 | 目标页面 | 特殊行为 |
|------|---------|---------|
| 启动 App | Splash → Server Connection | 无历史记录 |
| 连接成功 | Server Connection → Workspace (Tab 0) | 清空历史 |
| 点击 Tab | 切换对应 Tab | 保留 Tab 状态 |
| 点击会话 | Workspace → Chat | 推入历史栈 |
| 点击返回 | Chat → Workspace | 弹出历史栈 |
| 设置中点击服务器 | Settings → Server Detail | 推入历史栈 |
| Server Detail 返回 | Server Detail → Settings | 弹出历史栈 |

### 2.2 历史栈管理

```typescript
let history: string[] = [];

function openChat(title: string) {
  history.push(currentScreenId);  // 保存当前页面
  showChatScreen(title);
}

function goBack() {
  const prev = history.pop();
  if (prev) showScreen(prev);
  else switchTab(currentTab);  // 回到当前 Tab 首页
}
```

### 2.3 两种页面模式

| 模式 | 页面 | 特征 |
|------|------|------|
| **主页面模式** | Workspace / Favorites / Settings | 有底部悬浮 Tab 栏 |
| **对话模式** | Chat | 全屏沉浸，无底部 Tab，`ignoreLayoutSafeArea` |

## 4. 会话项 (Session Item) 规格

### 4.1 结构

```
┌─────────────────────────────────────┐
│  🟢  HarmonyOS NEXT 开发      ⭐    │  ← 或消息数徽章
│      3 分钟前 · mimo-v2.5           │
└─────────────────────────────────────┘
```

### 4.2 组成元素

| 元素 | 说明 | 样式 |
|------|------|------|
| 状态点 | 在线/离线 | 7px 圆形，绿色/灰色 |
| 标题 | 会话标题 | 14px，单行截断 |
| 收藏星标 | 已收藏时显示 | 14px，黄色 |
| 消息数徽章 | 未收藏时显示消息数 | 11px，半透明背景，8px 圆角 |
| 元信息 | 时间 + 模型名 | 12px，灰色 |

### 4.3 交互

- 点击 → 进入聊天页面
- 按压 → 背景变亮 `rgba(255,255,255,0.03)`

## 5. 会话分组 (Session Group) 规格

### 5.1 结构

```
┌─────────────────────────────────────┐
│  📁  dsh-harmonyos       4 会话  ▸  │  ← 分组头（可折叠）
├─────────────────────────────────────┤
│  （会话列表）                        │  ← 展开时显示
│  ...                                │
└─────────────────────────────────────┘
```

### 5.2 组成元素

| 元素 | 说明 | 样式 |
|------|------|------|
| 图标 | 渐变背景方形 | 32px，10px 圆角 |
| 名称 | 项目/工作区名 | 15px，500 字重 |
| 计数 | 会话数量 | 12px，灰色 |
| 箭头 | 展开/折叠指示 | 16px，灰色，旋转动画 |

### 5.3 折叠行为

- 默认展开（`open` 状态）
- 点击分组头切换展开/折叠
- 折叠时隐藏 `.sg-sessions`（`display:none`）
- 箭头旋转：`open` 时 90°，折叠时 0°

## 6. FAB 按钮规格

### 6.1 位置

```css
position: absolute;
bottom: 110px;   /* 在 Tab 栏上方 */
right: 20px;
```

### 6.2 样式

- 尺寸：52px × 52px
- 圆角：50%（圆形）
- 背景：蓝色渐变 `linear-gradient(135deg, #4a9eff, #3b82f6)`
- 阴影：`0 4px 20px rgba(74,158,255,0.35)`
- 光晕：`::after` radial-gradient 脉冲动画 2.5s
- 文字：白色 `+`，28px

### 6.3 交互

- 按压：`scale(0.88)` + 阴影减弱
- 点击：`alert('新建会话 → session/create API')`
